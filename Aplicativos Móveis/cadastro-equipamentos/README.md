## 📋 Sobre o Projeto
Este é um aplicativo móvel desenvolvido em React Native com Expo. O sistema atende aos requisitos do Trabalho Final, consistindo em uma aplicação básica com formulário de cadastro, listagem de dados em memória (utilizando estado) e exclusão de itens. O tema escolhido para este CRUD é o Cadastro de Equipamentos de Informática.

## 🛠️ Pré-requisitos
Antes de começar, você precisará ter instalado em sua máquina:
* [Node.js](https://nodejs.org/)
* Git
* Aplicativo **Expo Go** instalado no seu dispositivo móvel (Android ou iOS).

## 🚀 Instruções de Instalação e Execução

Siga o passo a passo abaixo para rodar a aplicação localmente:

### 1. Clonar o repositório
Abra o seu terminal e clone este repositório utilizando o comando abaixo (lembre-se de substituir a URL pelo link real do seu repositório no GitHub):

```bash
git clone [https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git](https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git)
```

### 2. Acessar a pasta do projeto
Navegue para o diretório clonado:

```bash
cd NOME_DO_REPOSITORIO
```

### 3. Instalar as dependências
Execute o comando abaixo para baixar e instalar todos os pacotes necessários:

```bash
npm install
```

### 4. Executar a aplicação
Inicie o servidor de desenvolvimento do Expo com o comando:

```bash
npx expo start
```

### 5. Visualizar no dispositivo
Após iniciar o servidor, um QR Code será exibido no terminal. 
* Abra o aplicativo **Expo Go** no seu celular (certifique-se de estar na mesma rede Wi-Fi do computador).
* Escaneie o QR Code.
* Aguarde o carregamento do *bundle* e a aplicação estará pronta para uso! (Se preferir, pressione a tecla `a` no terminal para abrir em um emulador Android ou `i` para emulador iOS).
